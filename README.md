# DeepForge

DeepForge is an AI project for image judgement using image models.

## Current Status

- *Judgement Models:* 2 image models are currently used for judgement
- *Training Data:* 14,000 images prepared for training
- *Training Status:* In Progress

> Once training is done, this documentation will be updated with model names, accuracy, and final results.

## How It Works

1. Collect Images - 14,000 images collected for training
2. Train Models - Train 2 image models on the dataset
3. Judgement - Models judge / classify / evaluate new images
4. Update - After training, update results here
